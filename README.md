# anandansundar.github.io

A lightweight personal portfolio for [anandansundar.github.io](https://anandansundar.github.io), built with plain HTML and CSS.

## Edit the portfolio

1. Open `index.html` and search for `EDIT:` comments.
2. Replace the clearly marked placeholder introduction, experience, projects, skills, and contact details.
3. Adjust colors or layout variables at the top of `styles.css` if desired.

Preview locally from the repository root:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploy

Because this is a GitHub user site, GitHub Pages serves the `main` branch at <https://anandansundar.github.io>. In the repository's **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder if Pages is not already enabled.
